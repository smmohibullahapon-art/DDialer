# DDialer - Telecom & Business Communication Platform
Powered by Dial Dynamic Ltd.

## Project Structure
- **/apps/web**: Next.js (TypeScript + Tailwind CSS) Customer Portal & Landing UI
- **/apps/api**: Modular Monolith Backend (NestJS / Node.js)
- **/packages/database**: Multi-tenant Prisma & PostgreSQL schemas
- **/deployments**: Docker compose & cluster configuration
